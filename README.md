
# Система учёта оценок студентов

## Описание проекта

Данная программа предназначена для управления списком студентов и их оценками.

## Возможности программы

1. Добавление студентов.
2. Просмотр всех студентов.
3. Поиск студента по имени.
4. Изменение оценки студента.
5. Удаление студента.
6. Вычисление среднего балла.
7. Поиск студента с самой высокой оценкой.
8. Просмотр студентов с оценкой 50 и выше.

## Проверки

- Проверка повторяющихся имён.
- Проверка оценок от 0 до 100.
- Обработка неправильного ввода.
- Проверка пустого списка.

## Используемые технологии

- Python 3

## Запуск программы

1. Открыть проект в PyCharm.
2. Открыть файл main.py.
3. Запустить программу кнопкой Run.
